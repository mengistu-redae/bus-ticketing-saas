############################
## building the fleet-management endpoints 
############################

endpoints (all OPERATOR_ADMIN-only, tenant-scoped)

┌────────┬───────────────────┬────────────────────────────────────────────────────┐
│ Method │       Path        │                        Body                        │
├────────┼───────────────────┼────────────────────────────────────────────────────┤
│ POST   │ /api/fleet/buses  │ { plateNo, capacity, seatLayout? }                 │
├────────┼───────────────────┼────────────────────────────────────────────────────┤
│ GET    │ /api/fleet/buses  │ —                                                  │
├────────┼───────────────────┼────────────────────────────────────────────────────┤
│ POST   │ /api/fleet/routes │ { origin, destination, distanceKm? }               │
├────────┼───────────────────┼────────────────────────────────────────────────────┤
│ GET    │ /api/fleet/routes │ —                                                  │
├────────┼───────────────────┼────────────────────────────────────────────────────┤
│ POST   │ /api/fleet/trips  │ { routeId, busId, departureAt, arrivalAt?, price } │
├────────┼───────────────────┼────────────────────────────────────────────────────┤
│ GET    │ /api/fleet/trips  │ —                                                  │
└────────┴───────────────────┴────────────────────────────────────────────────────┘

Creating a trip auto-generates its seats from the bus's capacity/seatLayout (e.g. "2x2" → 4 seats/row: 1A,1B,1C,1D,2A,...; unparseable layouts fall back to plain 1..capacity), all in one transaction — the same shape as BookingWriter/CancellationService.

Try it — as demo-operator-admin

- URL: http://localhost:3000/auth/login
- Username: demo-operator-admin
- Password: changeme123

// 1. Create a bus
fetch('/api/fleet/buses', {
  method: 'POST', headers: {'Content-Type':'application/json'},
  body: JSON.stringify({ plateNo: 'DEMO-002', capacity: 8, seatLayout: '2x2' })
}).then(r => r.json()).then(console.log)
// 2. Create a route (use a new city pair so it doesn't collide with the seeded one)
fetch('/api/fleet/routes', {
  method: 'POST', headers: {'Content-Type':'application/json'},
  body: JSON.stringify({ origin: 'Addis Ababa', destination: 'Bahir Dar', distanceKm: 560 })
}).then(r => r.json()).then(console.log)
// 3. Create a trip - use the ids returned above
fetch('/api/fleet/trips', {
  method: 'POST', headers: {'Content-Type':'application/json'},
  body: JSON.stringify({
    routeId: '<ROUTE_ID>', busId: '<BUS_ID>',
    departureAt: new Date(Date.now() + 2*86400000).toISOString(),
    price: 800
  })
}).then(r => r.json()).then(console.log)
